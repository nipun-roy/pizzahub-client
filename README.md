# PizzaHub Client

Pizza ordering and delivery platform frontend built with Next.js (App Router), Tailwind CSS, ShadCN UI, and Better Auth.

## Features
- Multi-role support: Customer, Vendor, Admin
- Dynamic menu browsing with advanced filters and price sorting
- ImgBB image uploading for vendors
- Vendor subscription management with Stripe
- Customer pizza ordering and order cancellation
- Responsive pizza-themed UI with Framer Motion animations
- Order status timeline tracking and dark/light mode toggle
